# Conecta Idosos — versão organizada em pastas

Esta é a versão do projeto **Conecta Idosos** com os arquivos separados em pastas (`html`, `estilização`, `img` e `script`), como foi entregue na disciplina de Desenvolvimento Web.

👉 **A versão principal, publicada e documentada, está em [Chiebao/Conecta-Idosos-Web](https://github.com/Chiebao/Conecta-Idosos-Web).**

![Preview do site](./Captura%20de%20tela%202025-10-18%20115524.png)

## Estrutura

```
index/
├── html/          # index.html, projetos.html e cadastro.html
├── estilização/   # base.css, layout.css, componentes.css e responsive.css
├── img/           # imagens do site
└── script/        # script.js (navegação, formulário e localStorage)
```
